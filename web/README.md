# TradingAgents Web

TradingAgents的Web界面版本，提供图形化的多智能体LLM金融交易分析工具。

## 功能特性

- 🖥️ **Web界面**: 现代化的Web界面，支持实时流式输出
- 🤖 **多智能体系统**: 包含分析师团队、研究团队、交易团队、风险管理团队和投资组合管理团队
- 📊 **实时状态监控**: 实时显示各个智能体的工作状态
- 📝 **流式报告**: 实时显示分析报告和消息日志
- ⚙️ **自动配置**: LLM配置自动从项目配置系统读取，无需手动设置

## 安装依赖

```bash
# 使用uv安装依赖
uv sync
```

## 启动Web应用

### 方法1: 使用启动脚本
```bash
python web/run.py
```

### 方法2: 直接运行
```bash
uvicorn web.main:app --host 0.0.0.0 --port 8000 --reload
```

### 方法3: 使用uv运行
```bash
uv run uvicorn web.main:app --host 0.0.0.0 --port 8000 --reload
```

## 访问应用

启动后，在浏览器中访问: http://localhost:8000

## 使用说明

### 1. 配置分析参数
- **股票代码**: 输入要分析的股票代码（如SPY、AAPL等）
- **分析日期**: 选择分析日期（默认为今天）
- **分析师团队**: 选择要启用的分析师类型
  - 市场分析师
  - 社交媒体分析师
  - 新闻分析师
  - 基本面分析师

### 2. 设置研究深度
- **浅度**: 快速研究，较少的辩论轮次
- **中度**: 适中的辩论轮次和策略讨论
- **深度**: 全面研究，深入的辩论和策略讨论

### 3. LLM配置
- **自动读取**: LLM提供商、API URL和模型配置自动从项目配置系统读取
- **配置显示**: 页面会显示当前使用的LLM配置信息（包括嵌入模型）
- **无需手动设置**: 用户无需在界面上配置LLM相关参数
- **统一配置**: 使用项目现有的config.py配置管理系统

### 4. 开始分析
点击"开始分析"按钮，系统将：
1. 启动WebSocket连接
2. 初始化交易代理图
3. 按顺序执行各个智能体的分析
4. 实时显示分析进度和结果

## 界面说明

### 智能体状态面板
显示各个智能体的实时工作状态：
- ⏳ **pending**: 等待中
- 🔄 **in_progress**: 进行中
- ✅ **completed**: 已完成
- ❌ **error**: 出错

### 消息日志面板
显示分析过程中的实时消息和工具调用记录。

### 当前报告面板
显示最新的分析报告内容。

## 技术架构

- **后端**: FastAPI + WebSocket
- **前端**: HTML + JavaScript + Bootstrap
- **实时通信**: WebSocket
- **异步处理**: asyncio

## 开发说明

### 项目结构
```
web/
├── main.py          # 主应用文件
├── run.py           # 启动脚本
├── README.md        # 说明文档
└── static/          # 静态文件目录
```

### 核心组件
- `ConnectionManager`: WebSocket连接管理
- `WebMessageBuffer`: 消息缓冲区
- `AnalysisRequest/AnalysisResponse`: API数据模型
- `run_web_analysis`: 异步分析任务

可以通过修改以下部分来扩展功能：
- 添加新的智能体类型

- 增加更多配置选项
- 优化用户界面

## 故障排除

### 常见问题

1. **端口被占用**
   ```bash
   # 使用不同端口
   uvicorn web.main:app --port 8001
   ```

2. **依赖安装失败**
   ```bash
   # 重新安装依赖
   uv sync --reinstall
   ```

3. **WebSocket连接失败**
   - 检查防火墙设置
   - 确认端口未被占用
   - 检查网络连接

### 日志查看
应用运行时会输出详细的日志信息，包括：
- 智能体状态变化
- 消息处理
- 错误信息
